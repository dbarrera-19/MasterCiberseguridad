# 1. Ordenador

**Descripción:** Es un dispositivo que utilizamos para trabajar, estudiar y guardar información.

**Riesgos:** Puede sufrir ataques de virus, averías o robos.

**Consecuencias:** Podemos perder archivos importantes o tener problemas para utilizarlo.

**Nivel de riesgo:** Alto.

**Soluciones:**
- Tener un antivirus actualizado.
- No descargar archivos sospechosos.
- Hacer copias de seguridad.

---

# 2. Contraseñas

**Descripción:** Sirven para proteger nuestras cuentas y evitar que otras personas entren en ellas.

**Riesgos:** Alguien puede descubrir o robar nuestras contraseñas.

**Consecuencias:** Pueden entrar en nuestras cuentas y robar información personal.

**Nivel de riesgo:** Alto.

**Soluciones:**
- Utilizar contraseñas largas y seguras.
- Activar la verificación en dos pasos.
- No compartir las contraseñas.

---

# 3. Red Wi-Fi

**Descripción:** Permite conectar nuestros dispositivos a Internet sin utilizar cables.

**Riesgos:** Personas desconocidas pueden conectarse a nuestra red sin permiso.

**Consecuencias:** Pueden utilizar nuestra conexión o intentar acceder a nuestros dispositivos.

**Nivel de riesgo:** Medio.

**Soluciones:**
- Poner una contraseña segura.
- Mantener actualizado el router.
- No compartir la clave con desconocidos.

---

# 4. Base de datos

**Descripción:** Es donde se guarda información importante, como datos de clientes, productos o trabajadores.

**Riesgos:** La información puede ser robada, borrada o perderse por un fallo.

**Consecuencias:** Una empresa puede perder datos importantes y tener problemas económicos.

**Nivel de riesgo:** Alto.

**Soluciones:**
- Hacer copias de seguridad.
- Permitir el acceso solo a personas autorizadas.
- Proteger la información con contraseñas.

---

# 5. Servidor

**Descripción:** Es un equipo que permite guardar información y ofrecer servicios, como páginas web o aplicaciones.

**Riesgos:** Puede sufrir ataques informáticos, averías o dejar de funcionar.

**Consecuencias:** Los usuarios pueden quedarse sin acceso a una página web o a sus archivos.

**Nivel de riesgo:** Medio.

**Soluciones:**
- Mantener el servidor actualizado.
- Utilizar un firewall para protegerlo.
- Hacer copias de seguridad.
